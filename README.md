### 👋 About me

Computer engineering graduate from Thailand. I finished my co-op at **MPD Engineering Co., Ltd.** (Khon Kaen, Jun–Oct 2026) and I'm now looking for my first full-time role.

I like making hardware and software work together for real: designing the circuit, writing ESP32 firmware, sending data over 4G/MQTT, and building the dashboard on top. I also run my own servers, from installing Linux to deploying services with Docker behind a Cloudflare Tunnel.

- 🎯 **Looking for:** IoT / Embedded Engineer · Junior Full-Stack Developer · DevOps / System Admin
- 📍 **Based in:** Khon Kaen, Thailand (on-site here, or remote)
- 🔭 **Lately:** MQTT + OTA firmware pipelines, RAG chatbots, Next.js 16
